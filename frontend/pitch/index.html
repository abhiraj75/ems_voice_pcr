108 Voice PCR Open the app

The patient report, filled in while the paramedic talks.

A voice copilot for India's 108 ambulances. The paramedic speaks in Hindi or English, a live agent asks for each detail and fills the report, and fixed safety rules flag risks while there is still time to act.

The problem

108 paramedics write the patient report by hand, usually after the run and from memory. Details get lost, the report isn't ready at handover, and mistakes are found when it's too late to fix them.

How it works

  1. It asks. One question at a time, only for what's still empty: patient, incident, vitals, allergies, history, treatment, handover.
  2. It writes and reads back. Every answer fills the form, and the agent repeats exactly what it recorded.
  3. It checks. After every change, rules catch allergy clashes, GCS 8 or below with no airway, shock index, low SpO2 and impossible vitals.

Built to be trusted

  • Questions, readbacks and alerts use fixed wording built from the form. The model only records data.
  • It explains terms like GCS, but never suggests a treatment.
  • Every value links to the exact words it came from; a value with no source is flagged.
  • Details that fit no field go to "Other details" instead of being lost.

Built on

Gnani Prisma v3.0 for speech-to-text, tuned with EMS drug and vitals terms, and Gnani Timbre v3.0 for the agent's voice, streamed in real time. Groq gpt-oss-120b runs the conversation. React and FastAPI.
